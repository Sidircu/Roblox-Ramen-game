# Sakura Ramen & Sushi Tycoon (titolo provvisorio)

Gioco Roblox tycoon: gestisci un ristorante giapponese di ramen e sushi, cucini al bancone, rifornisci le mensole dal magazzino, assumi personale, ingrandisci il locale e lo arredi su una griglia personalizzabile.

## Documenti
1. [Game Design](docs/01-GAME-DESIGN.md) — cosa c'è nel gioco e come si gioca
2. [Piano tecnico](docs/02-PIANO-TECNICO.md) — architettura, sistemi, ordine di implementazione
3. [Bilanciamento](docs/03-BILANCIAMENTO.md) — prezzi, ricette, sblocchi, formule

## Stato
Fase di progettazione completata. Prossimo passo: implementazione completa (blocchi B0–B8 del piano tecnico).

## Strumenti
- [Rojo](https://rojo.space) per compilare il codice in un file `.rbxl` da aprire in Roblox Studio
- [graphify](https://pypi.org/project/graphifyy/) per il grafo della conoscenza del progetto (`graphify-out/`)
